# Shop Brownie Removal

**By m3yessir · Mabinogi NA · v0.1.1-beta**

I made this mod to reduce personal-shop clutter. It hides brownies and their names while keeping shop signs usable. This update also blocks brownie dialogue to prevent accidental conversations through Ctrl+F. Tested in game.

## Install

1. Download the ZIP from [Releases](https://github.com/m3yessir/mabinogi-shop-brownie-removal/releases).
2. Close Mabinogi and remove older brownie-removal versions, including any test packages.
3. Extract the ZIP and put `m3yessirShopBrownieRemoval_00002.it` in your active package folder. Keep the filename unchanged.
4. Restart Mabinogi.

To uninstall, close the game, remove the .it file, and restart.

## Notes

- Some housing brownies may also become invisible and lose dialogue because they share the same models and races.
- **Don't combine with Bri HP Bars** or other mods replacing Race.xml or these brownie models. See [conflicts](CONFLICTS.md).
- May need updating after game patches.
